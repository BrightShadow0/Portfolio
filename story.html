03 / RESEARCH

Locating the break

I participated in ICDEC 2026 with this paper. When a team of AI agents writes code together and a vulnerability shows up at the end, which hand-off introduced it?

HOSA (HAND-OFF SECURITY ATTRIBUTION) LOGS EVERY TRANSITION, SO A VULNERABILITY TRACES BACK TO THE STEP THAT INTRODUCED IT

The draft proposes a security-specific failure taxonomy, an attribution method that scores each hand-off, and an evaluation protocol. A full-scale, multi-model evaluation is ongoing. Open the draft PDF or read the full summary.
